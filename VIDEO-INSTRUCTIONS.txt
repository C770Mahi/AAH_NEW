===============================================
   HOW TO ADD BACKGROUND VIDEO TO YOUR WEBSITE
===============================================

Your website currently shows a beautiful animated gradient background.
To add a VIDEO background, follow these simple steps:

STEP 1: DOWNLOAD A VIDEO
-------------------------
Choose one of these FREE video websites:

Option A - Pexels (Recommended):
1. Go to: https://www.pexels.com/videos/
2. Search for: "luxury interior" or "construction" or "modern house"
3. Find a video you like
4. Click "Download" and select "Full HD" or "HD"

Option B - Pixabay:
1. Go to: https://pixabay.com/videos/
2. Search for: "interior design" or "construction"
3. Download the video

Option C - Coverr:
1. Go to: https://coverr.co/
2. Browse "Architecture" or "Business" categories
3. Download any video you like

STEP 2: PREPARE THE VIDEO
--------------------------
1. Find the downloaded video file (usually in your Downloads folder)
2. RENAME the file to: background.mp4
   (Make sure it's exactly "background.mp4" - lowercase)

STEP 3: PLACE THE VIDEO
------------------------
1. Copy the "background.mp4" file
2. Paste it in the SAME FOLDER as your main.html file
   (This folder: C:\Users\AH02867\Downloads\MAHESH\aah_new\)

STEP 4: REFRESH THE WEBSITE
----------------------------
1. Open your website in the browser
2. Press F5 to refresh
3. The video should now be playing in the background!

===============================================

TROUBLESHOOTING:
----------------
- If video doesn't play:
  • Make sure the file is named exactly: background.mp4
  • Make sure it's in the same folder as main.html
  • Make sure it's an MP4 file
  • Try a smaller video file (under 10MB works best)

- The animated gradient background will show if:
  • No video file is found
  • Video file is too large
  • Video format is not supported
